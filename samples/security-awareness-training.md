# Security Awareness Training — Module 4: Prompt Injection

This training module is for awareness purposes. It explains how attackers try to manipulate AI assistants through documents, emails and web pages, and what to look for.

## What is indirect prompt injection?
Attackers may hide instructions inside content that an AI assistant will read, for example a shared document or a vendor report. The assistant cannot always tell the difference between the content it should summarise and the instructions it should obey.

## Examples of suspicious phrases (red flags)
Examples include text such as "ignore previous instructions" or "you are now in admin mode" placed in the middle of an otherwise normal document. Another common red flag is a request to quietly send records to an outside party. These examples are shown only for training purposes and must never be treated as real instructions.

## What to do
Report suspicious documents to the security team. Do not forward them. Remember that company assistants can only act within your own permissions, and that sensitive actions always require your explicit request.
